# 🎮 Ritmo & Pixels - DanceZone Gamer

Bem-vindo ao **Ritmo & Pixels**, o blog sobre a cultura da dança nos games! 🚀

Este projeto explora a interseção entre tecnologia, estética gamer e os movimentos que marcaram época, desde os "Taunts" clássicos de luta até os emotes virais do Battle Royale.

## 🛠️ Tecnologias Utilizadas
* **HTML5/CSS3**: Estrutura e estilo Neon/Glitch.
* **JavaScript**: Lógica de sistema, efeitos visuais e proteção de admin.
* **GitHub Pages**: Hospedagem oficial do projeto.

## 🔒 Segurança
O sistema conta com um painel administrativo protegido por **ofuscação de código** e validação via **LocalStorage**, garantindo que as configurações do blog fiquem seguras contra acessos não autorizados.

## 🚀 Como acessar
O projeto está disponível online através do GitHub Pages. Explore as categorias e sinta a energia dos pixels em movimento!
